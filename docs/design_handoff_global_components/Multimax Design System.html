Design System

Multimax × ERPNext v15

A mobile-first design language for the Multimax fulfillment app, built on the visual grammar of Frappe / ERPNext v15 — Inter type, a calm neutral gray scale, the signature #2490EF blue, and the colored-dot status indicators that make DocType lists instantly scannable on the warehouse floor.

Inter Light + Dark Mobile-first Scan-ready

Foundations

Color

A single neutral ramp carries 90% of the UI. The blue accent is reserved for primary actions, links and focus. Every status communicates through ERPNext's colored-dot indicators — never through layout.

Space · Radius · Elevation

Components

Buttons

One primary action per view. Secondary actions stay neutral; subtle buttons recede into toolbars. All targets are ≥44px tall for gloved, on-the-move tapping.

Components

Status indicators

ERPNext's defining pattern. A colored dot plus a label encodes document state. Use the dot-only .indicator inline in dense rows; use the filled .pill when status leads a card.
